# Game "Animals"

## Process
1. Person starts a game.
2. A root animal is a cat: animal = cat
2. Program asks him "Is this an ${animal}?"
3. If this is a true, program wins and exits.
4. If this a false, program try to find another animal.
5. If animal is found, go to step 3.
6. If animal is not found, program says "I surrender. What is it?"
7. Person enters a new animal.
8. Program asks to enter a question to distinguish the new animal from the last supposed one.
9. Program updates an entry for the last supposed, adds a new animal to it's database and exits.
